# Phoenix 后端 M1 设计包

本目录给出 M1 后端落地需要的三部分：

1. 数据库表设计：`sql/schema.sql`
2. REST API 清单：`api/rest-api-list.md`
3. 推荐目录结构：`dir-tree.md`

## 覆盖范围（M1）
- 科目体系初始化
- 凭证录入、审核、记账、作废
- 发生余额表
- 科目明细账 / 辅助明细账
- 会计期间与操作留痕

## 下一步开发建议
1. 先建立 `book/subject/voucher` 三个核心模块。
2. 先打通 `创建凭证 -> 审核 -> 记账 -> 余额表查询` 最短链路。
3. 加上会计期间开关控制，再扩展批量审核与批量记账。
